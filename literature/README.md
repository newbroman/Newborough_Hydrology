# store/ — reference library

Third-party reference material, kept locally so it can be read from the working
copy. **The contents of this folder are not committed** — see the `store/` block
in `.gitignore` and the reason there: this repository is public and this material
is under publisher or agency copyright.

This manifest is tracked. It is the versioned record of what the analysis was
read against, which is what a reader needs; the documents themselves are obtained
from their publishers.
