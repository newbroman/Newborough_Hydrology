# literature/ — reference library

Third-party reference material, kept locally so it can be read from the working
copy. **The contents of this folder are not committed** — see the `literature/*`
block in `.gitignore` (this README is the one tracked file) and the reason there: this repository is public and this material
is under publisher or agency copyright.

This manifest is tracked. It is the versioned record of what the analysis was
read against, which is what a reader needs; the documents themselves are obtained
from their publishers.

## Open-licence text for the chatbot

`literature/open/` is the one tracked subfolder: plain-text extracts of works
whose licence permits redistribution (CC BY), each headed with its citation,
licence and source. The project chatbot (`tools/build_chat_corpus.py`) may carry
these in full; everything else here it cites from the manifest above and never
contains.
