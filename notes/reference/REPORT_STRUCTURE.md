# Report structure — Newborough Warren (durable reference)

*Stable structural map for project knowledge. Records the report's skeleton — which
subdocument holds which chapter, the numbering scheme, where figures live. Does NOT
record live editing status (cross-ref conversion state, current figure totals,
task progress) — that belongs in per-chat handover documents, not here.*

## The document is a LibreOffice master

`report.odm` is a master document; each chapter is a separate `.odt` subdocument
linked from it via `xlink:href="../reportN.odt"`. The master's `styles.xml`
definitions win over the subdocuments' — subdocument style *names* resolve against
the master's *definitions*.

**Editing:** open each `.odt` **standalone** (never edit through the master).
**Verifying numbers:** always in an **exported PDF**, never in the master's editing
view (on-screen fields lag until recomposed). **Never** press Ctrl+Shift+F9 in the
master (recomposes all embedded images at once — has crashed the machine); refresh
via Navigator ▸ Update ▸ Selection.

Canonical `.odm` lives on the operator's machine and in two cloud mirrors
(Google Drive + pCloud, both ~77 KB). The `.odt` binaries are large (report4 /
report9 ~200 MB, figures embedded at high DPI) and are **gitignored** — the
committed record is the pandoc **text mirror** at `report_edits/text/reportN.md`,
regenerated by `report_edits/make_text_mirror.sh` (nrg_git.sh option 2).

## Figure numbering — two labels per figure

Captions are **auto-number fields**. The field resolves against whatever document
renders it:

- **Master** (`report.odm`): continuous across all chapters — `Figure 58`.
- **Standalone** (`report9.odt` alone): the subdocument's only chapter restarts the
  counter — the same figure reads `1.55`.

Both are correct. The master number goes to press; the standalone number is what
you see while editing and what the Cross-reference dialog lists.

**Offset (report9):** standalone = master − 3 (Study Site takes 1–2, Methods takes
3, so Results starts its master run at 4 = standalone 1.1).

**Panels** ending in a letter (3b, 16b, 46b) are cross-reference fields tracking a
parent caption; they do not advance the counter.

## Cross-references

In-text figure references in `report9.odt` are (being) converted to
**cross-reference fields** (Insert ▸ Cross-reference ▸ Figure ▸ Numbering), so they
follow the master's numbering automatically and cannot drift.

**Hard constraint:** cross-reference fields **cannot span subdocuments**. Only a
chapter's references to its *own* figures can be fields. References from Methods /
Discussion / Limitations / Conclusions *into* Results figures must stay typed text
— but those chapters contain few/no figures, so nothing renumbers beneath them.

In the Cross-reference dialog, figures are listed by **standalone** label
(`1.1`…`1.63`) and caption text. Pick the target by **caption text**, never by the
number being replaced — the numbers cannot match by construction.

## Section anchors

Headings carry `<span id="anchor-N">` ids in the mirror (pandoc artefacts of
LibreOffice bookmarks). `anchor` = chapter heading; `anchor-1`, `anchor-2`, …
number sections within each subdocument independently (each file restarts at
`anchor`). Section *numbers* (§4.9.4 etc.) are typed in the prose and can lag the
live document — confirm against the operator's `.odm`, not the mirror or the PDF.

## Editing workflow

- **Reference/number corrections:** delivered as search-string lists, verified
  against a fresh PDF export's caption sequence.
- **Prose/section edits:** JSON manifest + `apply_report_edits.py` (operator runs
  locally; default interactive walk shows before/after y/n/q; `--yes-all` skips it;
  each edit carries `expect_count`).
- **Figure-reference integrity:** `report_edits/figref_lint.py` reads the exported
  PDF, reports caption-sequence gaps/duplicates, dangling references, and
  unreferenced figures. Wired into nrg_git.sh option 2 (warns, never blocks).
  Reads the PDF, so export before linting.
