Privacy policy: NRG Drive client

The NRG Drive client is a private Google OAuth client used by one person, Martin Hollingham, to copy the working documents of the Newborough Warren hydrology study between his own computers and his own Google Drive with rclone. It is not offered to anyone else.

What it can access. It asks only for Google's drive.file permission, which lets it see, create and change only the files it has itself created in the signed-in user's Drive. It cannot see any other file in that Drive.

What it collects. Nothing. No data is sent anywhere except between the user's own computer and the user's own Google Drive. Nothing is stored by, shared with or sold to any third party, and no analytics or advertising are used.

Removing access. Access can be withdrawn at any time from Google Account → Security → Third-party access.

Contact. Through the project's GitHub issues page.
